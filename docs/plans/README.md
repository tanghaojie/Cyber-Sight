## 使用规则

- 非简单改动开始前，从[计划模板](../templates/implementation-plan-template.md)创建文件。
- 计划必须写清范围、非目标、依赖、任务、验证和回滚策略。
- 实施时更新复选框和偏差，不要让计划停留在最初设想。
- 完成、取消或被替代后移入 `archive/`，并保留最终状态和原因。
