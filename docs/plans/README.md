## 生命周期

- 非简单改动开始前，从[计划模板](../templates/implementation-plan-template.md)创建 `active/YYYY-MM-DD-<topic>.md`。
- 实施中更新任务、偏差和验证结果。
- 完成、取消或被取代后写入最终状态，并移入 `docs/archive/plans/`。
- 历史计划只在需要复盘迁移、回归或旧方案时从[归档索引](../archive/README.md)查找。
