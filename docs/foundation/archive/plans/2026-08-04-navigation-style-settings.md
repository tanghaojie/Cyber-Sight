# 导航菜单风格设置

## 目标

让系统设置中的侧边/顶部导航风格实际切换应用壳并持久化；窄屏始终使用无开关的侧边导航。

## 背景与设计依据

settings 模块已提供受校验的设备级 `navigationMenuStyle` 持久化。应用壳只消费其公开状态，不改变菜单树、路由或权限规则。

## 范围

- 在应用壳监听已保存导航风格和窄屏媒体查询。
- 侧边风格下始终显示侧边导航，移除所有侧栏开关与遮罩。
- 顶部风格下显示既有递归顶部导航。

## 非目标

- 不改变其他系统设置项、菜单数据、API 契约或动态路由。
- 不新增前端自动化或浏览器测试。

## 前置条件和风险

- 窄屏强制侧边模式不能覆盖已保存的桌面偏好。
- 媒体查询监听必须在组件卸载时移除。

## 实施任务

- [x] 接入导航风格与窄屏媒体查询。
- [x] 重构 Header、Sidebar 与布局，移除侧栏显示控制。
- [x] 格式化、类型检查和生产构建。
- [x] 归档计划与 AI 协作记录并提交。

## 测试与验证

执行 `pnpm format`、`pnpm format:check`、`npx vue-tsc --noEmit` 和前端生产构建；由维护者人工验收两种风格持久化、窄屏强制侧栏与窗口恢复后的风格还原。

## 发布与回滚

变更仅限浏览器界面壳。回滚提交即可恢复此前的固定顶部导航与移动抽屉。

## 实际偏差和遗留问题

无功能偏差。前端自动化与浏览器测试不在仓库维护范围内，导航行为由维护者人工验收。
