# 扩充 SVG 图标库

## 目标

为管理端补充可由菜单配置直接选用的常见单色 SVG 图标。

## 背景与设计依据

前端通过 `src/assets/icons/*.svg` 和 `icon-registry.ts` 在构建期生成 SVG sprite；文件名即稳定图标名。

## 范围

- 新增常用导航、资源、操作和状态图标。
- 明确图标文件的命名、画布与继承颜色约定。

## 非目标

- 不改变菜单数据、图标注册逻辑或现有图标名称。
- 不引入第三方图标依赖或前端自动化测试。

## 前置条件和风险

- 图标必须保持 `24 × 24` 画布和无硬编码颜色，才能与现有 sprite 和 CSS 颜色继承一致。
- 前端交互由维护者人工验收。

## 实施任务

- [x] 确认 SVG sprite 注册表及现有资产约定。
- [x] 新增 24 个常用 SVG 图标资产。
- [x] 更新前端设计中的图标资产约定。
- [x] 格式化、静态检查、生产构建并归档记录。

## 测试与验证

- 执行 `pnpm format`、`pnpm lint`、`pnpm format:check` 与 `pnpm build`。
- 维护者人工确认菜单图标下拉选项和侧栏显示效果。

## 发布与回滚

图标仅为新增静态资产；如需回滚，移除本次新增文件即可，不影响既有菜单名称。

## 实际偏差和遗留问题

首次受限沙箱中的 `pnpm build` 因 Vite/esbuild 无法读取父目录而失败；在授权环境原样重跑后成功，确认是沙箱访问限制而非项目回归。前端视觉与菜单交互仍待维护者人工验收。
