# 菜单动态布局

## 目标

让目录和菜单从前端 `src/layouts/*.vue` 自动发现的选项中选择布局，并让数据库菜单生成的动态路由使用布局继承与覆盖规则。

## 背景与设计依据

现有路由固定使用 `AdminLayout`。ADR-0010 的受控页面注册原则继续适用于布局，具体规则见 ADR-0017 和前端应用壳设计。

## 范围

- 菜单共享契约、数据库字段、迁移和后端映射。
- 前端布局注册表、菜单表单、动态路由和测试。
- 当前设计、ADR、计划与 AI 记录。

## 非目标

- 不支持运行时上传布局或数据库文件路径 import。
- 不为目录新增 URL，也不改变按钮外链行为。

## 前置条件和风险

- 保留工作区中既有 `SidebarTree.vue` 排版修改，不覆盖或据为本任务改动。
- 布局重命名会令旧标识无法解析；执行路由应拒绝未知布局。

## 实施任务

- [x] 更新契约、Schema、迁移和菜单仓储映射。
- [x] 创建布局注册表并接入菜单管理表单。
- [x] 递归生成带布局的动态路由并补充测试。
- [x] 完成构建、测试、文档归档和提交验证。

## 测试与验证

已运行契约包构建、后端构建与 53 项测试、前端生产构建与 33 项测试；迁移生成、根路径动态路由和 Git 空白检查通过。

## 发布与回滚

发布前先执行新增列迁移。回滚应用代码时保留可忽略的 `layout` 列；若必须回滚数据库，可删除该列，但会丢失布局选择。

## 实际偏差和遗留问题

全量前端测试暴露既有健康检查只创建轮询、不执行首次请求，导致其原有测试失败。为满足仓库验证门禁，补充挂载时首次请求，并让侧栏测试显式隔离健康网络依赖。此偏差不改变菜单布局设计。
