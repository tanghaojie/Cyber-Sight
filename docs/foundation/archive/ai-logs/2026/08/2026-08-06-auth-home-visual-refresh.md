# AI 协作记录

## 用户目标

读取根目录 README 的项目亮点、项目介绍和项目重点，重新设计登录页、首页展示内容和文字，让访问者第一眼看到 Cyber Scaffold 的关键价值。保留登录页“让复杂系统，清晰生长。”与首页“让系统脉络可见，让每次变更有据可循。”两组核心主张。

## 关键指令与约束

- 遵守根目录 `AGENTS.md` 的暂存区门禁、文档门禁、格式检查、前端人工验收边界和归档流程。
- 使用 `frontend-design` 技能，产出有明确审美方向的生产级 Vue 页面，不引入图片或新的运行时依赖。
- 不修改认证、导航、API、数据库和主题令牌的行为。

## 重要假设

- 这是展示层重设计，不需要新增长期架构决策或 ADR。
- 项目 README 是当前项目价值文案的首要来源；固定文案继续通过模块本地化资源维护。
- 动态快捷入口数量和名称仍由当前用户的导航权限决定，静态项目能力只作为首页首屏的解释层呈现。

## 方案选择

采用“编辑化系统蓝图”视觉方向：登录页使用深色品牌场景承载定位与证据，表单区强调入口清晰度；首页使用大面积 Hero、指标条、工程支柱和动态入口分层呈现，让项目价值、当前状态和下一步操作互不争抢。

## 实际改动

- 更新 `auth.locales.ts`：将登录页固定文案改为更直接的工程工作台入口，并补充模块边界、共享契约、持续演进、访问环境、本地开发账号和统一权限说明。
- 重构 `LoginPresentation.vue` 的文案结构：保留“让复杂系统，清晰生长。”，新增人类与 AI 共用工程蓝图提示和三项支柱的解释文字；保留 CSS-only 全息场景与 reduced-motion 行为。
- 重构 `LoginInteraction.vue` 的表单信息层级：增加工作台访问/本地就绪状态、登录说明、开发账号提示和统一权限安全提示；认证 store、redirect 和输入行为保持原样。
- 更新 `home.locales.ts`：保留“让系统脉络可见，让每次变更有据可循。”，增加项目状态、三项工程支柱、当前入口和空状态文案。
- 重构 `HomePage.vue`：将首屏拆为价值 Hero、工程支柱区和权限驱动的当前入口区；动态入口仍来自导航 store，新增空状态，不生成静态业务菜单。
- 更新 `docs/design/modules/auth.md` 与 `docs/design/modules/home.md`，使当前设计描述最终页面组合、信息层级与边界。
