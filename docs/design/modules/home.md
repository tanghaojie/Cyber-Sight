# 工作台模块

## 职责与边界

`home` 提供登录后的总览页面，并从导航模块读取当前用户可访问入口生成快捷卡片。它不维护静态业务菜单，也不拥有其他模块数据。

当前工作台首屏由三层组成：

1. Hero 保留“让系统脉络可见，让每次变更有据可循。”主张，并同时展示项目名称、模块/契约/文档状态、当前账号可访问入口数量和 README 中的三项基础能力摘要。
2. 工程支柱区用固定本地化文案解释模块边界、共享运行时契约和持续演进的项目价值；这些文案不读取业务统计，也不伪造运行时数据。
3. 当前入口区从 `navigation.flatItems` 过滤首页后取前四个菜单或外链，保留原有权限语义；无可用入口时显示配置提示，而不是生成静态菜单。

Hero、工程支柱、快捷卡片和状态强调只消费全局语义主题令牌，因此六套主题及深色模式无需修改页面逻辑即可同步更新。页面固定文案由 `home.locales.ts` 提供，中英文切换不影响动态菜单标签解析。

## 公共接口与测试

`registerViews.ts` 向动态页面注册表登记工作台懒加载器；`constRoutes.ts` 同时把 `HomePage.vue` 作为 `/` 下的默认静态子路由。页面人工验收关注默认入口、导航入口映射、空菜单状态和响应式布局；业务统计接入前需另建数据所有者设计。

首页 Hero 同时展示可点击的 CYBER Logo 和 GitHub 项目入口。Logo 复用品牌组件，外链使用新窗口安全属性，不改变首页静态路由和当前用户导航数据流。
