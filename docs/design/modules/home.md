# 工作台模块

## 职责与边界

`home` 提供登录后的总览页面，并从导航模块读取当前用户可访问入口生成快捷卡片。它不维护静态业务菜单，也不拥有其他模块数据。Hero、快捷卡片和状态强调只消费全局语义主题令牌，因此六套主题及深色模式无需修改页面逻辑即可同步更新。

## 公共接口与测试

`registerViews.ts` 向动态页面注册表登记工作台懒加载器；`constRoutes.ts` 同时把 `HomePage.vue` 作为 `/` 下的默认静态子路由。页面人工验收关注默认入口、导航入口映射、空菜单状态和响应式布局；业务统计接入前需另建数据所有者设计。
