# 前端错误页面模块

## 职责与边界

`errors` 拥有前端应用级错误页面展示。当前只提供 404 页面，不处理 HTTP 响应分类、业务错误消息或导航状态；这些职责分别属于共享 HTTP 错误处理器和调用方模块。

## 公共接口与依赖

- `error.routes.ts` 暴露 404 页面懒加载器 `notFoundPage`，供路由组合根配置显式 404 和兜底路由。
- 模块仅依赖 Vue 路由组件类型与本模块页面，不依赖其他业务模块。

## 数据流和失败模式

路由组合根把未知路径重定向到 404 页面，并保留来源路径供展示或诊断。页面加载失败由前端构建与运行时资源错误处理，不在本模块引入业务重试。

## 测试策略

前端路由测试覆盖显式 404、未知动态路径与公开页面行为；生产构建验证懒加载路径可以解析。
