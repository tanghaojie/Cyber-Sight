# 前端错误页面模块

## 职责与边界

`errors` 拥有前端应用级错误页面展示。当前提供 404 和已认证无页面权限状态，不处理 HTTP 响应分类、业务错误消息或菜单权限计算；这些职责分别属于共享 HTTP 错误处理器、调用方模块和导航模块。

## 公共接口与依赖

- `error.routes.ts` 暴露 `notFoundPage` 与 `noAccessPage` 懒加载器，供路由组合根配置显式 404、兜底路由和受认证保护的无权限页。
- 模块仅依赖 Vue 路由组件类型与本模块页面，不依赖其他业务模块。

## 数据流和失败模式

路由组合根把未知非根路径交给 404 页面；已认证用户在动态路由中没有任何可渲染站内页面时进入无权限页。无权限页使用管理端布局提供账号菜单和退出入口，但不自行读取权限 Store。页面加载失败由前端构建与运行时资源错误处理，不在本模块引入业务重试。

## 验证策略

前端生产构建验证懒加载路径可以解析；显式 404、未知动态路径、空权限无权限页、退出入口与公开页面行为由维护者人工验收。
