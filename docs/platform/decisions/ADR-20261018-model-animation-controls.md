# ADR-20261018：已加载模型的动画发现与独立播放

## 背景与决策

维护者明确要求把带动画模型的播放入口加入外部数据已加载资源操作区。采用当前 glTF 内嵌动画发现与资源局部播放器；每次选择单个片段，避免自动混播。局部秒数通过 Cesium animationTime 回调求值，RAF 推进并请求渲染，不修改场景唯一 viewer.clock。

控制器与资源共同释放，隐藏资源及后台页暂停。UI 条件按钮和内嵌面板不持有 Model。不扩展 AIModels 发布 v1，不猜测同目录文件或解析制作附录；静态主模型依旧静态。该决策扩展制作 ADR 所述普通模型消费能力，保留静态/动画独立交付规则与 DEV 预览隔离。

## 结果与风险

通用动画与建筑拼装可复用入口，场景昼夜及模拟航线继续使用原时钟。多片段切换沿用 glTF/Cesium 通道语义，没有动画混合、自动恢复所有未覆盖属性或资产协议迁移。GPU 性能、实际显示和交互由维护者人工验收。

## 验证与复审

按[动画控制设计](../design/modules/geo-model-animation.md)进行工程检查与人工验收。以后增加目录动画发现、片段混合、瓦片动画或跨资源统一时间时重新评审。
