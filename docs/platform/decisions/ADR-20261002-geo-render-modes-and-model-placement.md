# 决策

按维护者明确授权新增场景级性能、平衡、兼容模式，性能名称表示最高显示质量及固定分辨率，平衡默认。模式统一配置分辨率、近地光照、阴影、环境与后期，不修改影像源。三模式都保留唯一viewer.clock、浏览器时区、各模型地理太阳求值和资源生命周期。

加载模型时对独立数据副本适配发光倍率；有效WGS84 metadata须先询问坐标来源，不静默覆盖输入。缺失定位高度时，选模型坐标采用地形采样；height_m继续表示建筑尺寸。取消不进入场景也不报失败。

此决策扩展外部模型ADR与浏览器太阳环境ADR：不选择逐模型Profile的原则继续有效；阴影默认关闭、统一夜间IBL0.2及固定环境更新时间由三档质量策略取代；新增可控后期。无资产后台、实时点光源、场景持久化，默认Google图层与扫描资产保持现状。

同时修正启动城市ADR的镜头行为：默认相机仅在Viewer初始化应用，异步预置加载完成不得夺走当前镜头。性能档允许独立轻量高亮柔光，平衡/兼容关闭，扫描材质不变。运行时资源/后期恢复和对话框overlay均属于Geo内部生命周期，不扩展跨模块接口。

## 风险与验证

性能模式使用原生像素可能增加高DPI GPU成本，提供明确模式说明；无支持的后期能力降级。高速环境图的时间预算牺牲部分更新时间精度，完整反射插值属于后续工作。遵循仓库前端人工验收边界。
