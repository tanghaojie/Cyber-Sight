# ADR-20261019：统一拍摄进度与浏览器逐帧输出

使用独立 Geo 拍摄插件，按绝对拍摄秒数求值相机、模型片段和场景日期，不新增 Cesium Clock。普通浏览和局部动画保持既有行为，拍摄期间通过可恢复租约暂停自主动画，结束归还。

镜头工程以版本化本地 JSON 保存，导入不自动加载远程资源。预览和导出复用同一求值函数。导出关闭默认循环、固定画幅与质量、等待资源稳定后逐帧采集；Mediabunny 使用 WebCodecs 编码并封装 MP4，fflate 输出 PNG ZIP。优先流式写盘，兼容下载设内存上限；明确编码不支持、超时、跨域与取消状态。

该决策扩展模型动画独立播放 ADR，统一控制只在拍摄会话期间生效，不把普通播放器绑定到昼夜倍率。不承诺自动避障、跨硬件像素一致、任意浏览器 4K 编码或跨域权限绕过。工程验证与人工 GPU/编码验收分开记录。
