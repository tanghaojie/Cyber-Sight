# 独立产品拆分后的仓库边界

## 目标与授权

维护者已确认迁移没有问题，并明确要求将已迁出的排版工具全部移出本仓库，后续由两个独立项目分别维护。此次授权包含原应用、专属资源、当前与归档文档，以及混合文档中的相关内容。

## 当前职责和数据流

Cyber-Sight 继续拥有 Geo 与平台业务，使用 Foundation 公共接口；独立产品不再作为 workspace、模块、构建入口或 Forge 同步保护路径存在。剩余 Vue、Pinia、Element Plus 等依赖按仍在使用的 workspace 保留，仅移除撤出应用专属依赖。

不增加新的公共接口或跨项目数据流，也不增加双向同步。独立项目的源码与文档不在本次来源删除中修改。创作者署名与产品能力分开，现有实验室品牌、版权和 Foundation 文档保留。

## 文档与历史边界

删除专属设计、决策、计划、协作记录、调研和截图；索引不再指向已删除文件。混合的集成与模板记录仅移除已撤出产品部分，保留其余证据并注明删减日期。本仓库只保留本次拆分的治理记录，不复制独立产品规范或继续维护其验收计划。Git 历史不重写，历史版本仍可通过 Git 追溯。

维护者追加授权修复原有历史文档链接。只调整 Platform 链接到可确认的现行或归档位置，保持历史决策和证据原意；引用 Foundation 时不修改其文件。目标记录没有保留时按 Git 历史定位原文，不用相似文档替代原计划，也不伪造恢复文件。

## 失败模式与验证

删除范围必须限制在来源仓库，防止误删独立项目。删除后检查 workspace 清单、锁文件和所有文本引用，检查文档相对链接，执行冻结安装、格式、Lint、架构、类型/生产构建、适用的仓库脚本/契约/后端测试及归档 CI。不新增或运行前端或浏览器自动化；静态验证不代表 Geo 人工效果验收。

完成前检查 diff，确认剩余业务源码、共享契约、Foundation 文档和实验室署名保持原样。失败时保留证据并修复来源配置，不通过恢复原应用作为旁路；必要回退使用后续普通提交，不重写已发布历史。

## 实际交付与验证

2026-10-08 已移除 35 个原应用跟踪文件及该应用的本地目录，删除 54 份专属文档/截图，清理同步清单和混合引用。锁文件仅移除撤出 workspace 与 11 个专属包，剩余 importer、包和快照内容一致；DOMPurify 3.4.13 仍由 Cesium 使用，按实际依赖保留。

冻结离线安装、格式、Lint、架构、四个 workspace 的类型/生产构建通过；10 项仓库脚本测试、契约产物校验及 17 个后端测试文件中的 143 项测试通过。686 个剩余应用、共享包和 Foundation 跟踪文件没有改动。产品路径/名称引用没有残留；Platform 相对链接检查从原有 80 处失效降到 0，其中 77 处恢复现有文件位置，3 处引用经本地 Git 核验且属于 origin 历史的固定提交。检查包含本次新增文档。

构建保留原有 Sass legacy API、Rollup PURE 注释及 Geo 大 chunk 提示；没有放宽门禁。前端/Geo 人工视觉验收不属于本次代码删除验证。最终归档 CI 为 NOT_DUE，任务记录完成归档，本轮提交通过关联文件 Git 历史定位；未推送或部署。
