# 桀士排版工作台 UI 与阅读交互

维护者批准 V2 设计并要求实施完整修改；电脑预览也必须有阅读外壳。应用仍为独立纯前端桌面工具。正文、配置、本地保存、历史版本与受控导出沿用[独立应用设计](jlab-wechat-editor.md)和[存储设计](jlab-wechat-editor-storage.md)。

## 视觉和空间

workspace 私有样式定义应用背景、表面、中性文字、边框、蓝色交互强调、状态色、圆角和阴影 tokens；文章配色独立，换主题不改变操作控件。顶栏52px、控件13px、辅助12px、最低11px。四区依次为品牌、快捷颜色、设置、保存与复制；宽度不足时仅顶栏内部横向滚动。保留800px桌面最小宽度、双栏比例、无占位分隔手柄和独立滚动。

左侧非模态覆盖抽屉最大320px，从顶栏下方至状态栏上方；编辑栏拖窄时钳制到该栏宽度，不遮挡右侧或改变分栏比例。打开设置退出专注、恢复原比例。九种章节卡片调用typesetting公共预览服务复用文章装饰规则；八组配色卡片展示标题、正文与引用。文字设置保留原范围，增加14/15/16/17字号、1.6/1.9/2.2行距及仅重置文字参数的按钮。

## 颜色和选区

typesetting公共颜色组件包裹Element Plus ColorPicker，展示当前色、推荐色和最近使用色；最多8个去重色以独立应用localStorage键保存，读取/写入失败只影响推荐记录，不阻止文章改色。article只依赖该公开呈现入口，无反向依赖，无跨浏览器吸管承诺。

article-preview 捕获有效正文选区，通过现有来源映射和revision发出TextSelection。鼠标/键盘选区完成后显示气泡：五个常用色、自定义、清除颜色。位置优先上方8px，顶部不足翻至下方，横向钳制到预览容器。代码、图片、装饰、固定结尾和模拟元信息不进入选区。混合无效选区整体拒绝。

弹出颜色面板前保存可序列化选区，鼠标点击气泡保留锚点；颜色命令由workspace编排，article公开清除服务保留未选中片段，不删除加粗/链接语义。改稿、重渲染、滚动、尺寸变化、Escape关闭气泡；无有效选择时顶部局部字色说明操作方式。气泡不提供第二套加粗标注，加粗由Markdown快捷格式操作。

## 编辑和阅读

Markdown原稿保留textarea、IME保护和Tab行为，增加标题、加粗、斜体、引用、代码、有序/无序列表快捷格式；变更通过原有事件和标注迁移命令。使用原生文本编辑命令保留支持浏览器的撤销链，不引入编辑器依赖。导入仍在原稿标题右侧。

手机375px与电脑760px画板都提供可关闭的阅读外壳。手机有模拟状态栏和微信导航；电脑有桌面阅读导航。两者都有模拟公众号/原创说明，不虚构作者、地区或发布时间。文章标题仍由原文唯一产生；模拟元信息在article根外，永不进入复制。空间不足时自适应并显示实际测得画板宽度。外壳开关为临时UI状态，不改变草稿或导出。专注模式退出恢复原比例。

## 稳定反馈与输出

临时消息使用悬浮Toast，不参与工作区布局；诊断入口保留图片/导出/失效标注明细。保存失败/暂停持续显示在顶栏，允许原有重试；不会因Toast消失而隐藏。失效标注提供显式清除，不删除有效标注。

输出共用typesetting规则：浅色终端代码块含三个纯内联装饰圆点、引用便签底色、表头底色与隔行底色。装饰标记在纯文本导出前移除；不依赖伪元素/绝对定位，不加入应用或阅读外壳。最终DOMPurify受控清洗仍执行，不能承诺微信保真。固定结尾提供名片、关注提示、往期链接片段，只有用户点击追加才写入结尾，不替换既有内容或自动启用；沿用现有localStorage保存与链接降级。

## 边界和验证

公共接口及失败模式见[模块设计](../modules/wechat-editor.md)。不引入后台、契约、UI框架或第三方编辑器。适用检查为格式、Lint、TypeScript、生产构建、所有权、应用模块和归档检查。不得新增或运行前端自动化测试。维护者人工验收800×720、1280×720、1440×900及125%缩放，重点验证选区/IME/撤销/恢复、左右抽屉、电脑和手机外壳、无布局抖动、输出与公众号手机明暗。

实施记录见[UI改造计划](../../plans/active/2026-10-05-jlab-ui-redesign.md)。代码已实现，格式、Lint、类型、生产构建、模块/所有权和归档检查已通过；人工交互与公众号粘贴仍待维护者。构建有第三方PURE注释及504.72kB主包提示，不影响构建成功。
