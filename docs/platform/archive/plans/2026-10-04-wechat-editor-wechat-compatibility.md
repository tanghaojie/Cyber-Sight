# 公众号编辑器 HTML 与 CSS 兼容规范调研

## 目标

在微排技术调研基础上，读取微信公开规范，形成可用于后续导出实现的标签、属性、样式、结构与素材规则。区分规范要求、源码实践、项目建议与待人工验收结论。

## 背景与设计依据

用户已了解富文本剪贴板原理，本轮要求确定公众号编辑器支持范围。主要证据为微信《编辑器插件开发规范》及其关联的官方结构校验仓库；草稿 API 与浏览器粘贴分别处理。
