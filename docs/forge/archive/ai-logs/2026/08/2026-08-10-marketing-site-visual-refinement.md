# 推广站截图与界面细节优化

## 用户目标和约束

维护者要求重做 Header 语言切换，使用提供的六张产品截图替换合成界面，并修复“03 / 核心体系”卡片空白。

## 关键问答与确认

- 六张截图依次对应首页、用户管理、角色授权、菜单管理、接口日志和系统设置。
- 继续保持语言切换只位于 Header。

## AI 的重要假设

- 提供的截图已经由维护者确认适合公开发布。
- 保留截图原始比例和内容，不进行生成式编辑或裁剪。

## 方案和执行摘要

- 使用站点本地静态资源，由 Vite 处理最终资源路径。
- 将合成 `ProductScene` 简化为真实截图画框。
- 语言切换改为带滑动选中底板的紧凑双语胶囊。
- 核心卡片在每个桌面网格行使用互补列跨度。

## 验证结果

- `pnpm lint` 通过。
- `pnpm build` 通过；六张图片均生成带哈希的构建资源。
- `pnpm format:check` 与 `pnpm docs:archive:check:ci` 通过，归档状态为 `NOT_DUE`。
- `git diff --check` 通过。
- 按仓库边界未创建或运行前端自动化、浏览器测试。

## 未决问题与下一步

- 前端视觉和浏览器行为由维护者人工验收。
