# 核心卡片语言切换显现修复

## 目标

修复推广站切换语言后“03 / 核心体系”卡片内容变为空白的问题。

## 背景与设计依据

核心卡片使用本地化 `feature.code` 作为 Vue `key`。切换语言会重建带 `.reveal` 初始隐藏样式的节点，而显现观察器只在页面挂载时注册，导致新节点保持透明。

## 范围

- 使用与语言无关的卡片位置作为稳定组件身份。
- 补充推广站本地化与显现动画的设计约束。

## 非目标

- 不调整卡片视觉、内容或滚动动画策略。
- 不创建或运行前端自动化、浏览器测试。

## 前置条件和风险

- 中英文核心卡片数组必须保持相同顺序和数量；当前内容满足该条件。

## 实施任务

- [x] 修复核心卡片的 Vue `key`。
- [x] 完成格式、Lint、构建和文档检查。

## 测试与验证

运行 `pnpm format`、`pnpm format:check`、`pnpm lint`、`pnpm build` 和 `pnpm docs:archive:check:ci`。维护者人工验证滚动到核心体系后往返切换中英文，卡片持续可见且内容正确更新。

## 发布与回滚

随现有 GitHub Pages 工作流发布；回滚本次提交可恢复旧行为。

## 实际偏差和遗留问题

按照定位结果完成最小修复，无实现偏差。格式、Lint、全仓生产构建和文档检查通过；浏览器往返切换语言仍由维护者人工验收。
