# 主题视觉回归修复计划

## 目标

修复六套主题在深色模式、品牌区域、工作台 Hero 与健康状态上的视觉断层，并重新设计每套浅色/深色色板，使主题切换保持协调、克制和可读。

## 实施步骤

1. 为每套主题定义完整的浅色和深色表面、文字、边界、品牌背景、Hero、光晕与状态令牌，消除选择器优先级冲突。
2. 把首页 Hero、快捷卡片、侧栏品牌区、登录页和健康状态中的硬编码绿色改为主题令牌。
3. 优化设置弹窗色板预览，使用户能同时理解每套主题的主色和深色基调。
4. 执行格式化、静态检查、生产构建，并按用户授权使用浏览器人工验收主题切换和深色模式。
5. 更新现行设计、归档计划与协作记录并提交。

## 验收

- 六套主题在浅色与深色模式下均有明显但协调的主题身份。
- 黑白灰、蓝、紫、橙的深色背景正确覆盖应用壳和组件表面。
- 首页 Hero、侧栏品牌区、登录页及健康状态随主题切换。
- 刷新后仍恢复选定主题与深色状态。

## 实施结果

- 六套主题均补齐浅色、深色画布、面板、文字、边界、品牌背景、Hero、品牌强调色和装饰节点令牌；深色规则使用不会被浅色主题覆盖的选择器优先级。
- 首页 Hero、模块卡片、侧栏品牌与健康状态、登录页、语言切换器和 404 品牌页已改为消费语义主题令牌。
- 设置弹窗色板改为同时展示浅色主色与深色主色，便于用户在切换前理解双模式基调。
- 浏览器逐项切换六套浅色与六套深色主题，确认各主题画布和 Hero 独立生效；深色登录页、侧栏品牌、健康状态和首页 Hero 均随主题联动，路由切换后仍保留选择。

## 验证结果

- `pnpm format`
- `pnpm format:check`
- `pnpm lint`
- `pnpm build`
- 浏览器人工验收：六套主题 × 浅色/深色模式，以及首页、系统设置、登录页、侧栏品牌和健康状态。
