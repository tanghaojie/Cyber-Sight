# 菜单图标前端必填校验

## 目标

阻止菜单管理弹窗在未选择图标时提交，并给出本地化错误提示。

## 背景与设计依据

菜单模块已将图标定义为必填业务数据；`MenuDialog.vue` 目前仅提供可清空的图标选择器，提交前没有校验。

## 范围

- 将图标字段标记为必填。
- 在提交请求前校验图标。
- 添加中文和英文错误提示。

## 非目标

- 不修改菜单 API 契约、后端校验或现有菜单数据。

## 前置条件和风险

前端模块不维护自动化测试；由维护者进行浏览器人工验收。

## 实施任务

- [x] 更新菜单对话框和本地化资源。
- [x] 执行格式、类型和构建验证。

## 测试与验证

执行 `pnpm format`、`pnpm format:check`、TypeScript 检查及前端生产构建；人工验证新建或编辑菜单时清空图标后无法保存。

## 发布与回滚

随前端发布；回滚本次提交即可恢复原有行为。

## 实际偏差和遗留问题

无实际偏差。前端自动化测试不在仓库维护范围内，交互仍由维护者人工验收。
