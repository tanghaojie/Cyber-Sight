# 文档治理与 AI 强制规则实施计划

## 目标

为个人通用脚手架和团队模板建立统一文档结构，使系统设计、模块设计、实施计划、长期决策和 AI 协作记录可以持续维护和回溯。

## 非目标

- 本次不修复现有运行时代码和契约重复问题。
- 本次不引入 CI、测试框架或文档站点生成器。
- 本次不保存完整聊天转录。

## 任务

- [x] 设计 `docs/` 信息架构和生命周期。
- [x] 补充系统、API、后端、前端和文档治理设计。
- [x] 将原始 Superpowers 计划移入统一归档位置。
- [x] 建立 Design、Plan、ADR 和 AI Log 模板。
- [x] 添加根 `AGENTS.md` 文档门禁和架构约束。
- [x] 校验链接、目录、Git 差异和文档一致性。
- [x] 归档本计划并更新索引。

## 验证

- 所有索引中的相对链接都能解析到仓库文件。
- `docs/` 目录符合 `docs/README.md` 中声明的结构。
- 原始计划内容没有丢失。
- `AGENTS.md` 明确覆盖非简单改动的开始和完成条件。

## 实际结果

文档结构、内部链接、必需文件和 Git 空白错误均已检查通过。原始 Superpowers 计划内容保持不变，仅移动到统一归档目录。

## 回滚

这些改动只影响文档和 AI 指令。需要回滚时可恢复原计划路径并删除新文档，不影响运行时代码。
