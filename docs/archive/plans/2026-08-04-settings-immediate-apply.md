# 系统设置立即生效

## 目标

移除系统设置弹窗的保存步骤，使每项选择、开关变化和恢复默认值立即应用并写入浏览器存储。

## 背景与设计依据

设置模块已由 Pinia Store 校验并持久化完整的设备级设置对象。弹窗此前维护独立草稿，只有点击保存才提交，阻断了已接入导航风格的即时反馈。

## 范围

- 让弹窗控件直接更新 `settings.store.ts` 的公开设置。
- 移除“保存设置”按钮及其文案，保留仅关闭弹窗的取消操作。
- 更新设置模块的现行行为与人工验收说明。

## 非目标

- 不新增尚未接入的主题、深色模式、Tags View、侧栏 Logo 或动态标题的功能消费者。
- 不修改设置存储格式、后端接口或自动化浏览器测试边界。

## 前置条件和风险

- 设置变更不再可由取消操作回滚；用户可通过“恢复默认值”立即重置。
- `localStorage` 不可写时仍保留本会话内存状态，沿用 Store 的既有降级语义。

- `pnpm format`：通过。
- `pnpm format:check`：通过。
- `npx vue-tsc --noEmit`：受沙箱文件访问限制，且提升权限后无法解析命令；前端生产构建内置的 `vue-tsc` 已成功通过。
- `pnpm --filter @scaffold/frontend build`：通过；仅有现有 Sass 弃用和 Vite 动态导入分包警告。
- `git diff --check`：通过。

前端交互由维护者人工验收：逐项变更后无需保存即生效，关闭后不回滚，刷新后设置仍可恢复。

## 发布与回滚

变更仅影响浏览器端界面偏好。回滚关联提交可恢复草稿和显式保存交互。

## 实际偏差和遗留问题

无功能偏差。仓库不维护前端自动化或浏览器测试；人工功能验收仍由维护者执行。
