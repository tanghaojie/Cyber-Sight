# 推广站截图与界面细节优化

## 目标

根据维护者反馈重做 Header 语言切换，使用六张真实产品截图替换合成界面，并消除核心体系卡片网格留白。

## 背景与设计依据

现行实现已经具备独立静态站、双语内容与滚动三维轮播。维护者提供了管理端首页、用户、角色授权、菜单、接口日志和系统设置六张截图，现行设计文档已更新为随站点发布真实截图。

## 范围

- 优化 Header 双语分段控件的比例、选中状态和微交互。
- 将六张截图作为站点本地资产接入桌面环形轮播和移动端列表。
- 调整中英文截图标题与说明，使文案与真实画面一致。
- 修复六张核心体系卡片在十二列网格中的断层。

## 非目标

- 不修改管理端、后端、API 契约或数据库。
- 不压缩、裁剪或改写维护者提供的截图内容。
- 不创建或运行前端自动化、浏览器测试。

## 前置条件和风险

- 截图由维护者确认可公开发布，且不含敏感生产数据。
- 原始 PNG 会增加 Pages 产物体积，但保留画质优先于本轮引入新的图片处理工具链。

## 实施任务

- [x] 建立截图资产映射并替换合成产品界面。
- [x] 重做 Header 语言切换控件。
- [x] 修复核心体系卡片网格跨度。
- [x] 更新文档、格式化并完成构建验证。

## 测试与验证

运行 `pnpm format`、`pnpm format:check`、`pnpm lint`、`pnpm build` 和 `pnpm docs:archive:check:ci`。维护者人工验收真实截图清晰度、三维轮播、移动端横向列表、语言切换和核心体系网格。

## 发布与回滚

沿用现有 GitHub Pages 工作流。回滚本次提交即可恢复合成界面、旧语言切换和旧网格。

## 实际偏差和遗留问题

六张原始 PNG 共约 3.1 MB，未额外引入图片压缩工具。功能、格式、Lint、生产构建和文档检查已通过；浏览器视觉行为继续由维护者人工验收。
