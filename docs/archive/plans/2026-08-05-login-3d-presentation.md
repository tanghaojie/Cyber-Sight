# 登录页三维展示与交互拆分

## 目标

将认证模块的登录页面拆分为左侧品牌展示组件与右侧登录交互组件，保持既有展示文字不变，并以符合 CYBER 主题令牌的 CSS 三维动画提升左侧背景的层次感。

## 背景与设计依据

现有 `LoginPage.vue` 已具有左右栏语义，但品牌展示、背景装饰和认证交互共处一个页面文件。认证模块设计、前端页面私有组件约定和 CYBER 品牌规范要求把页面内部职责收敛在 auth 模块内，并继续使用主题语义令牌、产品/创作者品牌层级和前端人工验收边界。

## 范围

- 新增 auth 页面私有的展示与交互组件，由 `LoginPage.vue` 仅负责布局组装。
- 保留 `auth.locales.ts` 中现有左侧文字内容、品牌 Logo 和创作者署名。
- 为展示组件实现纯 CSS 的透视网格、悬浮几何体、轨道和数据流动画，并支持减少动态效果偏好。
- 保持认证 API、store、路由跳转和移动端内容语义不变。

## 非目标

- 不修改登录接口、令牌、认证状态或翻译文案。
- 不新增动画库、图像资源或前端自动化测试。
- 不调整应用壳及其他模块。

## 前置条件和风险

- 三维效果必须只使用已定义的主题令牌，避免固定为单一品牌色。
- 装饰元素必须对辅助技术隐藏，正文保持可读；减少动态效果偏好时必须停用连续动画。
- 仅靠静态检查和生产构建不能替代维护者对桌面、窄屏与不同主题的浏览器人工验收。

## 发布与回滚

本次仅改动前端私有页面结构和样式，随前端构建发布。若需回滚，可还原本次提交，不涉及数据迁移、接口兼容或会话变更。
