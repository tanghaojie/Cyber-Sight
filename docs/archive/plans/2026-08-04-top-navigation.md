# 顶部级联导航

## 目标

在桌面端实现默认仅显示一级菜单、任意深度子菜单按 hover 级联展开的顶部导航。

## 背景与设计依据

复用 navigation 模块提供的权限过滤递归菜单树，不改变菜单契约、权限过滤或动态路由注册。

## 范围

- 新增递归顶部菜单呈现组件。
- 在应用 Header 接入菜单树，并将桌面应用壳改为单列。
- 保留窄屏侧栏抽屉作为紧凑导航。

## 非目标

- 不变更菜单数据、API 契约、权限规则或路由生成。
- 不新增前端自动化或浏览器测试。

## 前置条件和风险

- 级联浮层必须保持父子 hover 区连续，并支持键盘焦点进入。
- 菜单树为空或包含空目录时不应渲染无效入口。
