# 2026-07-22 HTTP 状态与全局拦截器

## 用户目标

除 HTTP 401、404、500 外，后端其他错误全部返回 HTTP 200，通过业务 `status` 判断类型；前端统一拦截三种全局 HTTP 错误，其余由业务模块自行处理。

## 关键决定

- 403、409、429 和外部依赖对应的 502/503/504 均转换为 HTTP 200，保留原业务错误码。
- 未分类内部异常保持 HTTP 500；未知路由保持 404；未认证保持 401。
- 共享 API Client 发布 `api:globalHttpError` 浏览器事件，应用壳层可据此接入路由跳转、登录和全局提示。
- HTTP 200 的非零 `status` 不触发全局事件。

## 实施与验证

已修改后端错误处理、前端响应拦截器及对应测试。`pnpm gen:api`、后端 16 个测试、前端 15 个测试、`pnpm build` 和 `pnpm test:db` 均通过。Vite 仍报告 CJS Node API 弃用警告，不影响构建结果。关联提交由本次任务完成时生成。
